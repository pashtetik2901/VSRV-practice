# Анализ исполняемого ELF-файла

## Цель работы

Цель работы — изучить, как программа на языке C представляется после компиляции в виде ELF-файла Linux.

Исходный код:

```c
#include <stdio.h>

int global_status = 404;

int main() {
    printf("Hello, world! Status: %d\n", global_status);
    return 0;
}
```

Программа компилируется командой:

```bash
gcc file.c -o result
```

После компиляции создаётся файл `result`, который далее анализируется с помощью утилит `file`, `readelf`, `nm` и `objdump`.

## Анализ файла

Команда:

```bash
file result
```

показывает, что `result` является 64-битным ELF-файлом для архитектуры `x86-64`, использует PIE и динамическую линковку.

Команда:

```bash
readelf -h result
```

показывает заголовок ELF. Точка входа программы:

```text
0x1060
```

По этому адресу находится функция `_start`. Именно с неё начинается выполнение программы, после чего управление передаётся функции `main`.

## Таблица символов

Команда:

```bash
nm result
```

показывает основные символы:

```text
0000000000004010 D global_status
0000000000001149 T main
0000000000001060 T _start
                 U printf@GLIBC_2.2.5
```

Переменная `global_status` находится в секции `.data`, так как она имеет начальное значение `404`.

Функции `main` и `_start` находятся в секции `.text`, содержащей машинный код программы.

`printf` является внешней функцией и загружается из библиотеки `glibc`.

## Основные секции

Команда:

```bash
objdump -h result
```

показывает секции ELF-файла:

- `.text` — машинный код;
- `.rodata` — строковые константы;
- `.data` — инициализированные глобальные переменные;
- `.bss` — неинициализированные данные;
- `.plt` и `.got` — используются для вызова функций из динамических библиотек.

В данной программе:

```text
.text   → main, _start
.rodata → "Hello, world! Status: %d\n"
.data   → global_status = 404
```

## Дизассемблирование

Команда:

```bash
objdump -d result
```

позволяет посмотреть машинный код функции `main`.

Основной фрагмент:

```asm
mov 0x2eb9(%rip),%eax   # global_status
mov %eax,%esi
mov %rdx,%rdi
call <printf@plt>
mov $0x0,%eax
ret
```

Сначала из памяти загружается значение `global_status`, затем подготавливаются аргументы для `printf`.

После этого выполняется вызов:

```asm
call <printf@plt>
```

что соответствует строке:

```c
printf("Hello, world! Status: %d\n", global_status);
```

Инструкция:

```asm
mov $0x0,%eax
```

соответствует:

```c
return 0;
```

## Вывод

В результате анализа было установлено, что программа компилируется в 64-битный ELF-файл для архитектуры x86-64.

Глобальная переменная `global_status` хранится в секции `.data`, функция `main` — в `.text`, а строка для `printf` — в `.rodata`.

Точкой входа является функция `_start`, которая передаёт управление `main`. Дизассемблирование показывает, как исходный код на C преобразуется в машинные инструкции.
